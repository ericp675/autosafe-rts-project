📋 Project Overview

AutoSafe Technologies is a simulated Orlando-based autonomous vehicle safety systems startup specializing in real-time collision avoidance. This project implements a safety-critical embedded system that guarantees microsecond-precision emergency responses for self-driving vehicles.

The system demonstrates the critical difference between hard real-time (where missing a deadline could cause a collision) and soft real-time (where delays only affect user experience). Built on ESP32 with FreeRTOS, it processes LiDAR sensor data, performs sensor fusion, and triggers emergency braking—all within guaranteed time constraints.

Why Real-Time Matters: In autonomous vehicles, a delayed obstacle detection or brake response of even 50 milliseconds could mean the difference between stopping safely and a collision. This system proves all safety-critical tasks meet their hard deadlines with measurable safety margins.

✨ Key Features

⚡ Hardware Interrupts

Emergency stop button triggers ISR with <5ms guaranteed response time for life-critical situations.

🎯 Hard Real-Time Tasks

Obstacle detection and sensor fusion with provable deadline compliance and safety margins.

🔄 FreeRTOS Scheduling

Rate Monotonic Scheduling ensures shorter-period tasks always get CPU priority.

🔒 Race Condition Protection

Mutex, semaphores, and queues prevent data corruption in multi-threaded environment.

📡 Multi-Channel Communication

Internal queues and event groups coordinate tasks; UART telemetry outputs to fleet management.

✅ Determinism Proof

Timestamp analysis and heartbeat LED demonstrate predictable, guaranteed timing behavior.

🎓 Learning Outcomes

Through this project, I demonstrated proficiency in:

  • Designing and implementing hard real-time systems with guaranteed deadlines
  • Rate Monotonic Scheduling and priority-based task assignment
  • Preventing race conditions using mutexes, semaphores, and critical sections
  • Hardware interrupt service routines (ISRs) with timing constraints
  • Multi-task synchronization in FreeRTOS embedded environment
  • Worst-case execution time (WCET) analysis and safety margin calculations
  • Professional embedded systems documentation and testing methodologies
